# Chapter 4: 个人展示与沟通方式

## Core Idea
个人展示是把"内心思考"压缩成"听得进的话"的能力——演讲稿结构、语言节奏、肢体配合 3 件事要做到位。

## Frameworks Introduced

### 1. 演讲的类型（按形式）
- **照稿演讲**：逐字稿，完全可控，但容易显得僵硬
- **记忆演讲**：背熟提纲，措辞临场——推荐（兼顾稳定和自然）
- **即兴演讲**：事先无准备，临场发挥
- **Use when**: 场合重要度 + 个人熟练度决定选哪种

### 2. 演讲稿"总-分-总"经典结构（出自 §4.1）
| 段 | 时长 | 作用 |
|---|---|---|
| **开场白** | ~1 分钟 | 开门见山 / 设置悬念 / 介绍情况 / 创设情境 |
| **主体 3-4 段** | 每段 2-3 分钟 | 时间 / 叙事 / 因果 / 事理 / 观点-材料逻辑展开 |
| **结尾** | ≤ 30 秒 | 哲理 / 鼓舞 / 激励 / 展望——可不必首尾对应 |

**主体段 5 种展开方式**：时间发展 / 叙事情节 / 因果关系 / 事理逻辑 / 观点-材料（并列/总分/综合）
- **Use when**: 任何 10-30 分钟演讲前的结构骨架

### 3. 演讲语言 3 特点
- **上口入耳，通俗易懂**：用听众熟悉的词，避免生涩 / 冷僻 / 学术术语
- **多用短句，简短有力**：避免长单句/长复句，每句一口气能说完
- **以理服人，以情动人**：理是骨架，情是血肉——并列，缺一不可
- **Use when**: 写完演讲稿后逐段检查

### 4. 演讲稿撰写 5 步
1. **审题**：明确主题、场合、听众、目的、核心信息
2. **确立主旨**：简洁、能贯穿全文
3. **构思素材**：从个人经历、典型案例、数据统计、历史事实切入
4. **遴选素材**：相关性、真实性、说服力
5. **分层次撰写**：处理层次、节奏、衔接
- **Use when**: 写命题演讲稿（指定题目）

### 5. 演讲的非语言技巧
- **站姿**：挺直，双脚略分开，与讲台保持 10-15 cm
- **目光**：扫视全场（从左到右 / 从右到左），重点对象多停留
- **手势**：辅助而非替代——手势与话意义一致
- **走动**：每 5-10 分钟换一次位置（避免僵化）
- **Use when**: 任何当众讲话

### 6. 即兴发言 4 步
- **破题**（30 秒）：用"听到 / 看到 / 想到……"引出话题
- **展开**（2-3 分钟）：用"我认为……原因有三……"结构
- **收束**（30 秒）：用"综上 / 所以"总结
- **升华**（30 秒）：引用名言 / 展望未来 / 回到主题
- **Use when**: 课堂讨论、会议临时发言、答辩追问

### 7. 成果展示 4 步骤
- **开场**：项目背景 + 你为什么做
- **方法**：用了什么方法 / 工具
- **结果**：数据 / 案例 / 截图 / 关键发现
- **反思**：不足 + 下一步计划
- **Use when**: 答辩、汇报、毕业设计、PRJ 展示

## Key Concepts
- **独白体**：演讲是独白体——一对多、声音为主
- **演讲稿 vs 提纲**：演讲稿是文字底稿，提纲是"结构 + 关键点"
- **照稿演讲 / 记忆演讲 / 即兴演讲**：演讲的 3 种熟练度
- **设问**：用一连串问题串起演讲——把听众卷入思考
- **节奏**：快慢 / 抑扬 / 轻重 / 虚实的循环交替
- **重音策略**：3 个重音依次递增（避免"一惊一乍"）

## Mental Models

### "照稿 vs 记忆 vs 即兴"——演讲形式选择矩阵（§4.1）
- 高度熟练 + 短演讲 → 即兴
- 中度熟练 + 重要场合 → 记忆演讲（提纲 + 关键词）
- 低度熟练 + 严格要求 → 照稿演讲
- **Use when**: 接到演讲任务的 30 秒内决策

### 演讲语言 3 原则（§4.1"以理服人，以情动人"）
- **理**：逻辑清晰、论证严密
- **情**：真挚动人、感染力强
- **情真意切**：情真（感情真挚）+ 意切（契合时代和听众）
- **Use when**: 演讲稿 review 时自检

## Anti-patterns
- **照本宣科读稿**：失去眼神交流、失去感染力 → 改用提纲
- **手势与话不一致**：说"3 条意见"比画"4" → 听众困惑
- **讲稿太长**：5 分钟读不完 → 改用结构 + 短句
- **理论堆砌不举例**：抽象 → 听众走神；用个人经历、典型案例拉回
- **演讲中不看 PPT 之外的人**：丧失与听众的连接
- **结尾讲不完就结束**：提前设计 30 秒内的硬结尾（戛然而止也行）

## Worked Example — 李燕杰《国家、民族与正气》的语速对比（出自 §4.1 课堂训练 1）

**两段对比语速**：

```
例一（讲解性，慢速）：
什么叫正气呢？正气就是所谓浩然之气，即孟子所说的"其为气也，
至大至刚""则塞于天地之间"。我们还可以把这种正气看作是中华
民族之魂。

例二（号召性，快速）：
青年朋友们，爱我们的国家吧，爱我们的民族吧，同心协力，
把我们民族的正气，把我们中华民族奋发图强的爱国主义精神
极大地发扬起来！
```

**作者总结**：
> "全篇的语速基调到底如何确定，哪儿应当快速，哪儿应当慢速，要在演讲时处理好。语速的变化还不能太突然，要有过渡，只能逐渐加快或减慢；否则，就会使听众感到突兀。"

**takeaway**：语速不是均匀的，要按"内容性质 + 情感强度"动态调整。
- **讲解、铺垫、叙述**：中速
- **抒情、号召、激励、抨击**：快速
- **思考、深情、悼念、宣告**：慢速
- **过渡段**：中速（让听众准备下一段）

**对应练习**：把任意一段话重写 2 遍——一遍刻意放慢、读出"思考感"；一遍刻意加快、读出"鼓动感"——对比听感差异。
