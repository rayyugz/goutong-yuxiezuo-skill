# Chapter 1: 语言表达与沟通概述

## Core Idea
沟通是带结果的行为（区别于"交际"——只指行为）；沟通分语言沟通和非语言沟通两条轨道，前者靠符号，后者靠体态语；非语言沟通的可信度通常高于语言沟通。

## Frameworks Introduced

### 1. 沟通的 5 要素（沟通者 · 信息 · 目的 · 环境 · 工具）
- **When to use**: 写汇报稿 / 设计演讲 / 准备一次关键面谈之前，先列五要素
- **How**: 对每个要素问"我选对了么？"——例如：信息要素要看"对方能听懂么"，工具要素要看"邮件 vs 电话 vs 面谈"

### 2. 沟通的类型（4 维度）
- 按正式程度：**正式 / 非正式**
- 按方向：**上行 / 平行 / 下行**
- 按反馈：**单向 / 双向**
- 按主体：**人际 / 群体 / 团队 / 组织 / 跨文化**
- **How**: 当你要换沟通方式时，先问自己"我现在在哪个维度上做事？"

### 3. 口语语体 13 类
演讲语言 / 辩论语言 / 播音语言 / 主持语言 / 教师语言 / 谈判语言 / 推销语言 / 求职语言 / 领导语言 / 采访语言 / 答辩语言 / 朗诵语言 / 外交语言
- **When to use**: 准备不同场景的表达时——面试用"求职语言"，课堂发言用"演讲/答辩语言"

### 4. 书面语体 4 类
**公文语体（程式规范）/ 科技语体（专业准确）/ 政论语体（观点鲜明）/ 文艺语体（形象生动）**
- **How**: 报告用公文语体，技术方案用科技语体，时评用政论语体，公众号用文艺语体

### 5. 体态语的 4 大沟通功能
**辅助传递信息 / 单独传递信息 / 强化有声语言 / 调节沟通心理**
- **Use when**: 你的语言已经够好，但对方仍无感时——大概率是体态语没跟上

### 6. 非语言沟通的特点 7 项
无意识性 / 情境性 / 可信性 / 社会性 / 个性化 / 生动性 / 文化性
- **Use when**: 解释"为什么我的内容都对，但对方没被打动"——可信度排在第一

## Key Concepts
- **语言沟通**：以语言（口语 + 书面语）为媒介，分音节、有确定语义
- **非语言沟通**：以体态语、空间、副语言为媒介，不分音节、语义不确定
- **首因效应**：两个陌生人初次见面形成的印象，对后续沟通起引导作用
- **交际 vs 沟通**：交际指行为，沟通强调"沟而通"——结果导向
- **独白体 vs 对白体**：说话者独自完成沟通 vs 至少两人沟通

## Mental Models

### 梅拉比安公式（交际效果 = 7% 文字 + 38% 声音 + 55% 表情）
- 准备一次重要沟通时，把训练时间按 5:3:2 分配给"表情与体态 / 声音 / 文字"
- 反过来，如果对方被打动了，55% 来自你看到了什么，38% 来自你听到了什么

### "先微信问能不能打电话"
- 文字 vs 电话 4 维对比：即时性 / 情感负担 / 记录追溯 / 效率
- **重大事打电话（不紧急可面谈），平常事用微信**——简单事直接用邮件
- 具体操作：不紧急但想打电话，先发消息大致说一下 + "我可以给您打个电话吗？"——给双方整理思路的时间

## Anti-patterns
- **"沟而不通"**：以为自己"沟通过"了，但对方没懂 / 没动 → 沟通必须以对方行动为结果
- **把书面语体念出来**：朗读"父亲，我回来了！"——这本来是书面语，硬念出来很奇怪
- **表情与内容割裂**：嘴上说"重要"，表情却平淡——听众会自动相信表情
- **手势与话不一致**：说"3 条意见"比画"4"——听众立刻困惑

## Worked Example — 无语练胆 + 自我介绍四要素（出自 §1.1）

作者在第一节给了两个训练：①无语练胆（两人轮流上台静默扫视全场 20 秒，训练上台不紧张的肌肉记忆）；②模拟竞选训练（小王想竞选班长，给班主任沟通）。

**小王与班主任沟通的四要素拆解**（作者原文分析框架）：

| 要素 | 小王的准备 |
|---|---|
| **沟通者** | 小王本人 → 要让对方感到自信、有诚意 |
| **信息** | 表达竞选意愿 + 阐述动机 + 展示优势 + 设想未来 + 询问意见 |
| **目的** | 争取班主任的支持与指导 |
| **环境 + 工具** | 提前了解班主任日程 + 选合适沟通途径 + 调整心态 |

**核心 takeaway**：沟通不是"想说什么"，而是"为了让对方做什么"。要素拆解把"我想说"转成"他需要听什么"。
